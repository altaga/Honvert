# Honvert

**Convert files. Nothing else.**

Honvert is an Android app for converting files directly on your phone. No cloud, no account, no ads, no subscriptions. Free.

## Status

Early scaffold. The home screen is a placeholder and no conversions are implemented yet.

## Run it

```bash
npm install
npm run android
```

## Stack

- Expo SDK 55 with Expo Router
- React Native 0.83, React 19
- Android only

## Origin

The project structure and UI foundation come from the `altaga-expo` template (MIT).
